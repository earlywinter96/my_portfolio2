## Run Locally

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev -- -p 4175
```

Open:

```text
http://127.0.0.1:4175/
```

## Build

```bash
npm run build
```

## Notes

Keep private keys in `.env`. Do not paste API keys into client components.
